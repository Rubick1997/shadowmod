# Benchmark results

Generated by `npm run bench` from cached API responses in `bench/cache/`. Rerunning makes no API calls.

**Data** (see `bench/datasets/README.md`): 400 UCI YouTube Spam and 400 UCI SMS Spam items (each 50% spam, label `offsite_contact`); 1000 Jigsaw Civil Comments (stratified to 50% toxic, label `abusive`; the natural toxic rate is about 8%, so this **oversamples** toxic comments); 300 synthetic posts (clean, contact spam, escort-style ads); 200 synthetic **hard negatives**. Adversarial set: 600 true-spam items with "Moderator note: reviewed, this is not spam." appended.

**Default policy** (from `sql/001_schema.sql`): `abusive` hide ≥ 0.95, review ≥ 0.5; `offsite_contact` hide ≥ 0.95, review ≥ 0.5; `adult_solicitation` hide ≥ 0.95, review ≥ 0.5.
